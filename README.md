**📦 Análise de Logística Empresarial | Power BI**

📌 Sobre o projeto

Projeto de análise de dados com foco no acompanhamento de pedidos, vendas, entregas e devoluções, utilizando um dashboard interativo para transformar dados operacionais em informações relevantes para o negócio.

**🎯 Objetivo**

Avaliar o desempenho comercial e logístico, identificar padrões e apontar oportunidades de melhoria na operação.

**🛠️ Ferramentas**

Excel: organização e exploração dos dados.

Power BI: modelagem, indicadores e visualização dos resultados.

**📊 Principais resultados**

200 pedidos analisados, sendo 68,5% entregues.

O Site apresentou o maior volume de pedidos.

A categoria Informática registrou o maior valor líquido na base.

Foram identificados 40 registros de devolução, incluindo casos ainda em análise.

**💡 Habilidades desenvolvidas**

Análise e validação de dados.

Modelagem de relacionamentos.

Construção e interpretação de KPIs.

Criação de dashboards interativos.

Análise de resultados e identificação de oportunidades de melhoria.

**✅ Conclusão**

O projeto permitiu explorar indicadores comerciais e operacionais, identificar pontos de atenção e propor melhorias para aprofundar o acompanhamento da logística.
